# Honda CRF 450 asset integration

The game optionally loads `res://assets/honda_crf450.glb`.

1. Download the original asset from its creator on Sketchfab:
   https://sketchfab.com/3d-models/free-honda-crf-450-c80f0e732e844580af412958c9d67315
2. Verify the exact license and attribution in the download page.
3. Convert the authorized source file to GLB if needed, and name it `honda_crf450.glb`.
4. Put it in this folder and commit it only if the license allows redistribution.
5. Verify orientation, scale, wheelbase and materials in Godot 4 Web.

Source model is NOT included in this repository. No claim of successful import or iPhone testing is made. The procedural fallback remains playable when the asset is absent.

If CC BY applies, provide creator attribution, original URL, license URL and modification notice in the game credits.
